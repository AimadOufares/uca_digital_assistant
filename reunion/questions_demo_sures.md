# Questions de demonstration sures

## Objectif

Ces questions sont conseillees pour une demonstration orale, car elles donnent generalement des resultats plus stables que les cas fragiles.

## Questions principales

### 1. UC@Student

Question :

```text
Ou consulter mes notes sur UC@Student ?
```

Pourquoi elle est utile :

- service bien reconnu ;
- document pertinent retrouve ;
- bonne demonstration d'un service etudiant.

Message oral :

> Ici, le systeme identifie le service UC@Student et retourne une reponse basee sur les documents lies au portail etudiant.

### 2. PEDOC

Question :

```text
Comment candidater sur PEDOC ?
```

Pourquoi elle est utile :

- service explicite ;
- bon retrieval ;
- montre la capacite du module a traiter un service doctoral.

### 3. CIP

Question :

```text
A quoi sert le CIP ?
```

Pourquoi elle est utile :

- reponse generalement claire ;
- montre une plateforme pedagogique ;
- utile pour expliquer les sources.

### 4. HPC UCA

Question :

```text
Comment acceder au calcul haute performance de UCA ?
```

Pourquoi elle est utile :

- service bien reconnu ;
- reponse orientee recherche ;
- montre que le corpus ne couvre pas seulement la scolarite.

### 5. Soutien-Recherche

Question :

```text
Ou trouver un accompagnement pour monter un projet de recherche ?
```

Pourquoi elle est utile :

- bon retrieval ;
- reponse utile ;
- montre les services pour enseignants-chercheurs / recherche.

## Scenario contextuel court

Ce scenario permet de montrer que le systeme garde le contexte.

```text
A quoi sert UCAPLAT ?
Comment deposer des devoirs ?
Et pour les cours ?
Comment candidater sur PEDOC ?
Et les documents necessaires ?
```

Comportement attendu :

- les trois premieres questions restent dans le contexte UCAPLAT ;
- la quatrieme question change clairement vers PEDOC ;
- la cinquieme utilise PEDOC comme contexte.

## Questions a eviter en demonstration live

Ces questions peuvent etre gardees pour l'analyse critique, mais pas comme premiere demonstration :

```text
A quoi sert UCAPLAT ?
Comment deposer des devoirs sur UCAPLAT ?
Comment suivre l'etat de mon diplome ?
```

Pourquoi :

- UCAPLAT est reconnu, mais certains chunks restent mal alignes ;
- Espace Diplomes peut encore etre partiellement confondu avec UC@Student ;
- ces cas sont mieux presentes dans la partie limites/perspectives.

## Plan de demonstration conseille

1. Se connecter a l'application.
2. Poser une question simple sur UC@Student.
3. Montrer la reponse, les sources et la confiance.
4. Poser une question PEDOC.
5. Poser une question de suivi.
6. Montrer l'historique de conversation.
7. Ouvrir le dashboard administrateur.
8. Montrer le healthcheck ou les metriques RAG.
